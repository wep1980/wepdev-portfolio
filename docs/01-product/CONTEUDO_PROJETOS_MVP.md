# Conteúdo dos Projetos do MVP

## 1. Objetivo

Este documento define o conteúdo inicial dos projetos que serão apresentados na seção Projetos em Destaque da WEPDEV Portfolio.

Os dados aqui descritos serão utilizados como fonte de verdade para a implementação do EP-006.

Nenhum projeto deve ser apresentado com informações fictícias, links inexistentes ou funcionalidades ainda não implementadas como se já estivessem disponíveis.

---

## 2. Regras gerais

Todos os projetos devem:

- ser autorais;
- possuir conteúdo público;
- respeitar propriedade intelectual e confidencialidade;
- utilizar descrições verdadeiras;
- indicar claramente quando estiverem em construção;
- não reutilizar código corporativo;
- não citar projetos internos;
- não expor credenciais, URLs privadas, ambientes ou dados protegidos;
- possuir links somente quando realmente existirem;
- permitir evolução futura para uma página própria de estudo de caso.

---

# 4. Projeto 2 — Laboratório Java com IA

## 4.1 Identificação

- ID: `laboratorio-java-ia`
- Slug: `laboratorio-java-ia`
- Nome: Laboratório Java com IA
- Categoria: Java e Inteligência Artificial
- Tipo: Laboratório
- Estado: Planejado
- Destaque: Sim

## 4.2 Problema

Desenvolvedores Java precisam integrar modelos de linguagem a aplicações empresariais, mas muitas demonstrações dependem exclusivamente de APIs pagas, não comparam modelos e não apresentam métricas úteis para tomada de decisão.

## 4.3 Solução proposta

Criar uma aplicação Java que permita experimentar e comparar modelos de Inteligência Artificial utilizando:

- Ollama como opção local e prioritária;
- OpenAI como integração opcional;
- comparação de respostas;
- medição de tempo;
- estimativa de tokens e custo quando aplicável;
- registro de avaliações;
- experimentos com prompts;
- evolução futura para RAG.

## 4.4 Tecnologias planejadas

- Java 21
- Spring Boot
- Spring AI
- Ollama
- OpenAI opcional
- Maven
- PostgreSQL
- Docker
- OpenAPI
- testes automatizados

## 4.5 Conceitos planejados

- integração com modelos generativos;
- abstração entre provedores;
- execução local de modelos;
- comparação de respostas;
- métricas de latência;
- controle de custo;
- avaliação de resultados;
- arquitetura modular;
- RAG em etapa futura.

- observabilidade;
