# Épicos — WEPDEV Portfolio

## 1. Objetivo

Este documento organiza o produto em grandes blocos funcionais.

Cada épico representa uma entrega relevante para o portfólio e será detalhado posteriormente em histórias, critérios de aceite e tarefas técnicas.

---

## 2. EP-001 — Identidade e apresentação profissional

### Objetivo

Apresentar Waldir Escouto Pereira de forma clara, profissional e objetiva.

### Entregas principais

- foto profissional;
- nome completo;
- cargo;
- resumo de posicionamento;
- principais tecnologias;
- chamadas para currículo, LinkedIn, GitHub e contato.

### Resultado esperado

O visitante deve compreender em poucos segundos quem é o profissional e qual é sua especialidade.
